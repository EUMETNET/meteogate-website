Frequently Asked Questions

Answers to common questions about MeteoGate, EUMETNET's gateway to open meteorological data.

What is MeteoGate?

MeteoGate is EUMETNET's open gateway to meteorological data from European national weather services, giving developers and researchers unified access to weather radar, warnings, surface observations and climate data through open APIs and a gateway interface.

Who can use MeteoGate's APIs?

MeteoGate's APIs are open to developers, researchers, public authorities and businesses building applications or analysis that rely on European weather and climate data.

Do I need an API key to access MeteoGate data?

No — an API key is not required to access most MeteoGate data, but registering for one through the API Key portal improves the service. Some restricted datasets require an API key for access.

Is MeteoGate data free to use?

Yes. MeteoGate provides open access to meteorological data from EUMETNET's member national meteorological services, in line with each dataset's published terms and conditions.

Which countries does MeteoGate cover?

MeteoGate covers data from most of the national meteorological services across Europe.

What is the Data Explorer?

The Data Explorer is a browser-based tool to preview and access MeteoGate's meteorological data without writing any code.
