Frequently Asked Questions

Answers to common questions about MeteoGate, EUMETNET's one-stop shop for official weather and climate data from national meteorological services across Europe.

What is MeteoGate?

MeteoGate is EUMETNET's one-stop shop for official weather and climate data from across Europe. As a European meteorological dataspace, it gives developers and researchers unified access to weather radar, warnings, surface observations and climate data from national meteorological services through open APIs and a gateway interface.

Who can use MeteoGate's APIs?

Anyone! MeteoGate's APIs are open to developers, researchers, public authorities and businesses building applications or analysis that rely on European weather and climate data.

What data can I access through MeteoGate?

MeteoGate provides access to a range of weather and climate data, including weather observations, radar data, warnings, and climate data. Available datasets depend on the contributing data providers.

Do I need an API key to access MeteoGate data?

Although an API key is not needed to access most data, registering for one through the API Key portal improves the service you receive. Some restricted datasets require an API key for access.

Is MeteoGate data free to use?

Yes. MeteoGate provides open access to meteorological data from EUMETNET's member national meteorological services, in line with each dataset's published terms and conditions. Check the licence or usage conditions for each dataset before using it.

Which countries does MeteoGate cover?

MeteoGate brings together data from the 33 national meteorological services across Europe which are members of EUMETNET.

How can I explore data without writing code?

Use the Data Explorer to discover datasets, preview available information and find links to access the data through APIs.

What is the Data Explorer?

The Data Explorer is a browser-based tool to preview and access MeteoGate's meteorological data without writing any code.

How do I access data through an API?

Browse available datasets through the MeteoGate Data Explorer and the MeteoGate portal, and follow the API links provided. Consult the relevant API documentation for endpoints, parameters and usage instructions.

Does MeteoGate store all the meteorological data?

No. MeteoGate provides a gateway to data supplied by national meteorological services and other providers. Data remains with the provider rather than being centrally stored by MeteoGate.

What is the relationship between MeteoGate and EUMETNET?

MeteoGate is an EUMETNET initiative that makes meteorological data from European national meteorological services easier to discover and access through a common gateway.
